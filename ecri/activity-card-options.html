Activity Card Design Options

Same data across all 3 options — pick the one that reads fastest

Option D1 — Opposed Daily Bars

Bars up = move-ins, bars down = move-outs. Each column = 1 day. Shows clustering vs spread.

Option D2 — Dot Strip Heatmap

Two rows (IN / OUT), one cell per day, color intensity = activity count. Pattern-readable at a glance.

Option D3 — Cumulative Area Ribbon

Two area fills building over time. The gap between curves = net. Shows pace and momentum.
